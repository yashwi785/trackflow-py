# trackflow-py
A lightweight, interactive command-line expense tracker built in Python. This project was developed to practice and demonstrate the practical application of foundational Python concepts—specifically dynamic loops, nested data structures, and modular function design.
🧠 Core Concepts Applied

Nested Dictionaries & Lists: Used structured dictionaries to represent individual expense records and lists to maintain the collection of records dynamically.

Control Flow & Loops: Managed the menu lifecycle using while loops, with for loops used for iterating through records and calculating totals.

Input Validation & Conditionals: Handled user choices, menu routing, and ensured valid numerical inputs.

Functions: Organized the application logic into modular, reusable blocks for readability and maintainability.
